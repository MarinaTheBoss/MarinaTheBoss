# Приложение «Вита» — цифровизация сети клиник

## Задача
Проанализировать и оптимизировать процессы записи на приём и обслуживания пациентов.

## Что сделано
- Провела анализ AS-IS и разработала TO-BE процессы в BPMN 2.0
- Сформировала и приоритизировала бэклог продукта
- Описала User Stories для команды разработки
- Разработала прототипы интерфейса
